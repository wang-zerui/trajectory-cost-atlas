07 · Method & provenance

口径先于结论

这张图在算什么

  • Token volume ≠ FLOPs ≠ provider invoice。页面同时给原始 token 与固定价格归一化成本。
  • Cache read 不重新做完整 prefill，但仍占上下文长度、decode attention，并产生 cache-read 费用。
  • 重写旧 history 可能摧毁廉价 cache hit；压缩应在 phase boundary 做稳定 checkpoint。
  • Pi action 分类按每轮第一个 tool call；OpenHands 按 ActionEvent 对齐 response usage。
  • Pi 文件内记录的 $2.0635 与统一 Opus 价格不一致，因此成本视图统一重算为 $12.4617，不混用原值。
  • 弱模型成本按用户假设置零；所有图只核算强模型侧。
