Where the money goes in real
Claude Code sessions

This page dissects 374 real Claude Code production sessions (56,594 main-agent model calls) from the SemiAnalysis cc-traces-weka-062126 corpus. Per-call cost is reconstructed from KV-cache block hashes at the published Opus 4.8 rate card. Three findings run through the whole page: cache read dominates cost, spend is back-loaded but not long-tailed, and these long sessions behave very differently from short benchmark runs like KernelBook.

01 · Cost Anatomy

Cost is cache read, not decode

Three cost components: prefill (writing new prefix into the cache), cache read (re-reading that prefix every call), and decode (tokens the model writes). Because Claude Code caches every new prefix, prefill here is the cache-write slice. Across all sessions cache read is 73% of spend and decode only 16% — the prefix you keep re-reading is the expensive part, not the output.

02 · Back-Loaded Cost

Later calls cost more than earlier ones

One real session, every call drawn as a stacked bar — each bar split into prefill, cache read and decode. Bars grow taller toward the right: as the prefix accumulates, the cache-read slice swells on every later call. Here the last calls cost about 2.8× the first. Nothing spikes — it is a steady climb.

03 · Cost Concentration

Back-loaded, but not long-tailed

If a few calls dominated the bill, this curve would hug the bottom then shoot up. Instead it stays close to the diagonal: across sessions the median point where half the cost is spent is 56% of the way through the calls. Cost accumulates steadily — you cannot save much by killing a handful of outlier calls.

04 · Trajectory Comparison

Short benchmark runs vs long production sessions

KernelBook is a short-task benchmark: a median of 4 turns per run, so one bar is essentially one strong-model call. SemiAnalysis sessions are real work — a median of 67 calls, up to 2,977. That length gap is why the back-loaded effect shows up in production but not in the benchmark.

05 · Method & Caveats

How these numbers were built

Costs are a faithful reconstruction, not a billing export. Read this before quoting absolute dollars — the shapes (mix, back-loading, concentration) are robust; the absolute totals are estimates.
